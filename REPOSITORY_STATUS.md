# Repository Status And Release Scope

This repository should remain **private before paper submission/publication**.

After acceptance or publication, the intended public release scope is:

- Source code.
- README and supporting documentation.
- Configuration examples and command-line usage notes.

The following are excluded unless separately licensed and explicitly added:

- Datasets and dataset splits.
- Model weights and pretrained checkpoints.
- Local ASR, CLAP, or emotion2vec model directories.
- Third-party assets, generated reports, and cached feature files.

Downstream users must respect the licenses and usage restrictions of any datasets, pretrained models, and third-party tools they use with this code. Speech forgery detection is a dual-use area; users should avoid surveillance, impersonation, privacy-invasive collection, or unsupported claims about individuals.
